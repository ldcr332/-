# -迷宫地图游戏（C语言）

地图生成算法  DFS深度路径搜索/回溯算法

```
伪代码如下
* 定义一个宽 W，高 H 的二维数组。全部填充为“墙”。
* 选一个起点 (x, y)，标记为“路”。
* 将起点压入栈 (Stack)。
* while (栈不为空) {
  从栈顶取出当前点。
  寻找当前点上下左右距离为 2 的未访问邻居。
  if (有未访问邻居) {
  随机选一个邻居。
  打通当前点和邻居中间的墙。
  将邻居标记为“路”，压入栈。
  } else {
  当前点出栈（回溯）。
  }
  }
* 最后，在四周的墙上开两个洞作为起点和终点。
```
